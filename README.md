# FRC AI Scouter
Welcome to the **in-progress** repository for Team 9470's AI scouter! This
repository contains tools for analyzing videos of robots playing the
2026 FIRST Robotics Competition Game, REBUILT. Due to the high volume of
game elements this season, we realized that making an automated analysis
solution would greatly improve not only our evaluation of our own robot, but
the evaluation of other robots during competitions, for scouting purposes. As tools are completed, they will be documented here.
